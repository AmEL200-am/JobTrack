
# JobTrack — Internship Tracking Website

JobTrack is a responsive website that helps students organize and track their internship applications.

## Features

- Add, edit, and delete internship applications
- Track application statuses
- Search and filter applications
- Dashboard displaying application statistics
- Store data using the browser's LocalStorage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## How to Use

1. Clone this repository.
2. Open `index.html` in your web browser.
3. Start managing your internship applications.
